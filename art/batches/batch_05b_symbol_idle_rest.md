Догенерация после приёмки пачки 05 (видео пришло только для M1, M2, M3, P, S, W). Условия те же: image-to-video, первый и последний кадр = PNG символа из `art/masters/symbols/` (наши мастера, не мастера пачки 05), 2 с, статичная камера, зелёный фон. Отдать как `sym_<ID>_idle.mp4` 512×512 на зелёном или анимированный WebP с альфой. Хвост промпта:
`VIDEO = static camera, no zoom, the object stays exactly in place and keeps its silhouette, same size, same lighting, same materials, subtle loopable motion, returns exactly to the first frame for a seamless loop, flat pure green background stays untouched, no new objects, 24 fps`
